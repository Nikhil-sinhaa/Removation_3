## Overview

**Removation.ai** is an AI-powered interior design & renovation platform with Vastu Shastra compliance built on Next.js 15. Users upload room photos, apply AI-driven design transformations (style changes, object removal, inpainting, enhancement, sketch-to-render), receive Vastu analysis, and get detailed cost estimates — all within a browser-based editor with a canvas (Konva).

## Data Flow

1. **Image Upload** → UploadThing → stored URL → attached to Project
2. **AI Generation** → User selects mode + style → API route → Replicate model → webhook callback → Render saved to MongoDB
3. **Vastu Analysis** → Room image + metadata → Groq LLM analysis → Vastu engine rules → compliance report
4. **Cost Estimation** → Room dimensions + materials + city → Cost engine → pricing database → detailed breakdown
5. **Payment** → Plan selection → Stripe (international) or Razorpay (India) → webhook → Subscription updated

## Conventions

**Naming:** PascalCase for components, camelCase for hooks/utils, kebab-case for routes
**Structure:** Feature-based grouping under `components/`, hook per feature, Zustand store per domain
**Styling:** TailwindCSS + shadcn/ui (Radix primitives) + CSS custom properties in `globals.css`
**Data Fetching:** Mix of SWR, TanStack React Query, and direct fetch calls
**Validation:** Zod schemas in `lib/validations.ts`
**State:** Zustand with Immer + Zundo (undo/redo) for editor, React Query for server state
